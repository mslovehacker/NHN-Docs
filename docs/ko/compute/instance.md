# Instance

NHN Cloud Instance는 가상 서버 컴퓨팅 자원입니다. 사용자가 원하는 OS 이미지와 하드웨어 사양을 조합하여 즉시 가상 서버를 프로비저닝할 수 있습니다.

## Instance 유형

| 유형 | 용도 | 권장 사양 범위 |
|---|---|---|
| **c2 (컴퓨팅 최적화)** | 일반 웹 서버, API, 컨테이너 | 2~16 vCPU |
| **m2 (메모리 최적화)** | 데이터베이스, 캐시, 분석 | 8~64GB RAM |
| **g2 (GPU 인스턴스)** | AI/ML 워크로드, 추론 서버 | NVIDIA V100 / A100 |

## Instance 생성 절차

### 콘솔 사용

1. NHN Cloud 콘솔에서 **Compute > Instance** 메뉴로 이동합니다.
2. **인스턴스 생성** 버튼을 클릭합니다.
3. 다음 항목을 순서대로 선택합니다.
    - 이름 및 설명
    - 가용성 영역
    - 인스턴스 타입 (예: `c2.c2m4`)
    - OS 이미지 (예: Ubuntu 24.04 LTS)
    - 네트워크 및 서브넷
    - Security Group
    - 키 페어
4. **인스턴스 생성** 을 확정하면 약 1~2분 후 사용 가능 상태로 전환됩니다.

## 보안 권장 사항

!!! warning "프로덕션 인스턴스 보안"
    프로덕션 환경의 인스턴스는 다음 원칙을 반드시 적용하시기 바랍니다.

    - 외부에서 SSH 접근은 **Bastion Host를 경유**하도록 구성
    - Security Group은 **최소 권한 원칙**으로 필요한 포트만 개방
    - **Floating IP를 직접 부여하지 않고** Load Balancer 뒤에 배치
    - 정기적인 OS 패치 적용
