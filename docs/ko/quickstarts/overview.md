# 빠른 시작 개요

NHN Cloud 서비스를 5분 안에 시작하는 방법을 안내합니다.

## 사전 준비 사항

- NHN Cloud 콘솔 접근 권한 (회원가입 완료)
- 결제 수단 등록 완료
- 기본 프로젝트 생성

## 권장 진행 순서

!!! tip "처음 사용자 권장 흐름"
    1. **프로젝트 생성**: 작업 단위가 되는 프로젝트를 먼저 생성합니다.
    2. **VPC 및 서브넷 구성**: 네트워크 격리 환경을 준비합니다.
    3. **Instance 생성**: 워크로드를 실행할 가상 서버를 생성합니다.
    4. **Security Group 설정**: 필요한 포트만 선택적으로 개방합니다.
    5. **외부 IP 할당**: 외부 접근이 필요한 경우 Floating IP를 연결합니다.
