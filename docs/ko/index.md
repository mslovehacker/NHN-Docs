# NHN Cloud 사용자 가이드

NHN Cloud의 모든 서비스에 대한 공식 사용자 가이드입니다. 본 가이드는 GitHub 저장소에서 관리되며, 각 페이지 우측 상단의 ✏️ 아이콘을 통해 누구나 개선 제안이 가능합니다.

## 시작하기

NHN Cloud를 처음 사용하시는 분은 [빠른 시작 가이드](quickstarts/overview.md)부터 확인하시기 바랍니다.

## 주요 서비스 카테고리

- **컴퓨팅(Compute)**: 가상 서버 인스턴스, NHN Kubernetes Service, Container Service
- **스토리지(Storage)**: Object Storage, Block Storage, NAS
- **네트워크(Network)**: VPC, Load Balancer, CDN, DNS Plus
- **데이터베이스(Database)**: RDS, Redis, Memcached, NoSQL
- **AI/ML**: AI EasyMaker, GPU Instance, AI Campus

## 본 가이드 활용 방법

!!! tip "효율적인 학습 순서"
    1. 빠른 시작 가이드로 전반적인 개념 이해
    2. 사용하실 서비스의 카테고리 가이드 학습
    3. 콘솔 또는 CLI를 통한 실습
    4. 공식 자격증(CES/CAA/CAP) 학습 자료 활용

## 문서 기여

오타 수정이나 내용 개선 제안은 페이지 우측 상단의 ✏️ 아이콘을 클릭하시면 GitHub에서 바로 수정하실 수 있습니다.
