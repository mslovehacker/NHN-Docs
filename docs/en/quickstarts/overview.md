# Quickstart Overview

This guide walks you through getting started with NHN Cloud services in five minutes.

## Prerequisites

- Access to the NHN Cloud console (registration completed)
- Payment method registered
- A default project created

## Recommended Order

!!! tip "Recommended flow for first-time users"
    1. **Create a project**: First create the project that will be your unit of work.
    2. **Configure VPC and subnets**: Prepare an isolated network environment.
    3. **Create an Instance**: Provision a virtual server to run your workload.
    4. **Configure Security Groups**: Open only the ports that are required.
    5. **Assign an external IP**: Attach a Floating IP if external access is required.
