# NHN Cloud User Guide

The official user guide for all NHN Cloud services. This guide is managed in a GitHub repository, and anyone can propose improvements via the ✏️ icon at the top right of each page.

## Getting Started

If you are new to NHN Cloud, please start with the [Quickstart Guide](quickstarts/overview.md).

## Main Service Categories

- **Compute**: Virtual server instances, NHN Kubernetes Service, Container Service
- **Storage**: Object Storage, Block Storage, NAS
- **Network**: VPC, Load Balancer, CDN, DNS Plus
- **Database**: RDS, Redis, Memcached, NoSQL
- **AI/ML**: AI EasyMaker, GPU Instance, AI Campus

## Contributing

Click the ✏️ icon at the top right of any page to edit it directly on GitHub.
