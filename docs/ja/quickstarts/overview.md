# クイックスタート概要

NHN Cloud サービスを 5 分で始める方法をご案内します。

## 事前準備

- NHN Cloud コンソールへのアクセス権限(会員登録完了)
- 支払い方法の登録完了
- 基本プロジェクトの作成

## 推奨手順

!!! tip "初めてのご利用に推奨されるフロー"
    1. **プロジェクトの作成**: 作業単位となるプロジェクトを作成します。
    2. **VPC とサブネットの構成**: ネットワーク分離環境を準備します。
    3. **インスタンスの作成**: ワークロードを実行する仮想サーバーを作成します。
    4. **セキュリティグループの設定**: 必要なポートのみを開放します。
    5. **外部 IP の割り当て**: 外部アクセスが必要な場合に Floating IP を接続します。
