# NHN Cloud ユーザーガイド

NHN Cloud のすべてのサービスに関する公式ユーザーガイドです。本ガイドは GitHub リポジトリで管理されており、各ページ右上の ✏️ アイコンから誰でも改善提案が可能です。

## はじめに

NHN Cloud を初めてご利用の方は、まず[クイックスタートガイド](quickstarts/overview.md)をご確認ください。

## 主要サービスカテゴリ

- **コンピュート(Compute)**: 仮想サーバーインスタンス、NHN Kubernetes Service、Container Service
- **ストレージ(Storage)**: Object Storage、Block Storage、NAS
- **ネットワーク(Network)**: VPC、Load Balancer、CDN、DNS Plus
- **データベース(Database)**: RDS、Redis、Memcached、NoSQL
- **AI/ML**: AI EasyMaker、GPU Instance、AI Campus
