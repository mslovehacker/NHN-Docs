# Instance

NHN Cloud Instance は仮想サーバーのコンピューティングリソースです。

## インスタンスタイプ

| タイプ | 用途 | 推奨スペック範囲 |
|---|---|---|
| **c2 (コンピュート最適化)** | 一般的な Web サーバー、API、コンテナ | 2~16 vCPU |
| **m2 (メモリ最適化)** | データベース、キャッシュ、分析 | 8~64GB RAM |
| **g2 (GPU インスタンス)** | AI/ML ワークロード、推論サーバー | NVIDIA V100 / A100 |

## インスタンス作成手順

1. NHN Cloud コンソールで **Compute > Instance** メニューに移動します。
2. **インスタンス作成** ボタンをクリックします。
3. 名称、ゾーン、タイプ、OS イメージ、ネットワーク、セキュリティグループ、キーペアを選択します。
4. 確定後、約 1~2 分でインスタンスが利用可能になります。

## セキュリティに関する推奨事項

!!! warning "本番環境インスタンスのセキュリティ"
    - 外部からの SSH アクセスは **Bastion Host を経由** するように構成
    - セキュリティグループは **最小権限の原則** に従い、必要なポートのみ開放
    - **Floating IP を直接付与せず**、Load Balancer の背後に配置
    - 定期的な OS パッチ適用
